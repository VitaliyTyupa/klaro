# Proposal

## Why

Klaro має допомогти користувачеві впевнено писати іноземною мовою та точно розуміти повідомлення без постійного перемикання між сторонніми сервісами. Потрібна єдина основа для корекції, перекладу й словникової довідки з контрольованими витратами, прозорим походженням даних і приватністю від першої версії.

## What Changes

- Створити Angular + Material розширення з бічною панеллю для Chrome, Edge і Firefox та вебзастосунок із більшим редактором, обліковим записом і налаштуваннями.
- Використовувати лише ручне введення / вставлення тексту й копіювання результату: без читання сторінок, стеження за сторонніми полями, автоматичного перенесення чи вставлення назад.
- Упровадити корекцію мови письма зі збереженням змісту, альтернативами, окремими правками, поясненнями на запит і автоматичним перекладом актуальної рекомендації рідною мовою.
- Додати переклад виключно між основною мовою та обраною мовою письма. Каталог першої версії: `uk`, `de`, `en`, `vi`; початкові налаштування: `uk` / `de`.
- Побудувати NestJS backend із REST і Socket.IO, автентифікацією, авторизацією, обліком операцій / токенів, лімітами та замінним AI provider adapter.
- Створити спільний довідник із ліцензійно дозволених відкритих джерел, підтримкою різних частин мови, оновленнями, поступовим розкриттям картки й окремо позначеними доповненнями ШІ.
- Закласти перевірки безпеки, приватності, доступності та готовності до магазинів розширень. Факт виконання плану не є гарантією юридичної відповідності чи схвалення магазином.
- Реалізовувати поетапно: platform foundation → correction → translation → lexical reference → release hardening. Майбутні аудіо, зображення та навчання врахувати лише як межі розширення модулів.

Поза обсягом: персональний словник, автоматичне виділення слів із текстів користувача, навчальна статистика, аудіозахоплення, Teams, зображення, переклад між двома нерідними мовами, платежі та постійна історія текстів. Довідкова база не є персональним словником.

## Capabilities

### New Capabilities

- `language-preferences`: основна мова, мови письма, напрямки перекладу, стиль та рівень володіння.
- `text-workspace`: редактор, межі обсягу, виділення, копіювання, тимчасові оригінали, актуальність результатів і доступність.
- `text-correction`: корекція, перефразування, правки, альтернативи, пояснення та зворотний переклад.
- `text-translation`: двосторонній переклад зі збереженням комунікативного змісту.
- `browser-extension`: панель, активація, browser adapters, дозволи та пакування.
- `account-management`: вхід, сесії, налаштування, вебкабінет, експорт і видалення даних.
- `operation-processing`: REST / Socket.IO контракти, кореляція, відновлення, квоти та облік використання.
- `ai-orchestration`: версійовані workflow, заміна моделей / провайдерів, валідація та ізоляція недовірених даних.
- `lexical-reference`: багатомовний пошук слова, значення, приклади, граматичні розділи та доповнення ШІ.
- `reference-data-management`: імпорт, походження, ліцензії, версії й оновлення спільної бази.
- `privacy-and-release`: мінімізація даних, розкриття обробки, безпека й критерії випуску.

### Modified Capabilities

Немає: на момент планування основні специфікації та реалізація відсутні.

## Impact

Зміна greenfield: у репозиторії наявні лише початковий README, конфігурація OpenSpec та службові файли; прикладного коду, залежностей і тестів немає. План передбачає клієнтські застосунки, спільні контракти, NestJS API, PostgreSQL, тимчасове сховище Redis та окремий процес імпорту довідника. OpenAI — початковий AI provider, але не частина клієнтського API.

Комунікація й описові документи проєкту — українською. Імена сутностей, файлів, API, технічні заголовки, коментарі коду й тестові ідентифікатори — англійською; користувацькі рядки локалізуються окремо. Ця зміна створює тільки планувальні артефакти; реалізація потребує окремого запуску apply.
