# Spec Delta

## Purpose

Забезпечити точний переклад для повсякденної комунікації між основною мовою користувача та обраною мовою письма.

## ADDED Requirements

### Requirement: Native anchored translation directions
Перекладач SHALL підтримувати лише основна мова → активна мова письма та зворотний напрямок. Перемикання напрямку SHALL не змінювати мовні налаштування профілю. Інтерфейс SHALL показувати вхід і переклад без третьої області зворотного перекладу.

#### Scenario: Reverse direction
- **WHEN** користувач з основною `uk` і мовою письма `de` перемикає напрямок
- **THEN** напрямок стає `de` → `uk`, основна мова залишається `uk`, додатковий переклад результату не виконується

#### Scenario: Unsupported cross language request
- **WHEN** клієнт надсилає запит `de` → `en` для основної `uk`
- **THEN** сервер відхиляє його до виклику провайдера

### Requirement: Communicative fidelity
Переклад SHALL зберігати комунікативний намір, факти, числа, заперечення, термінологію та структуру абзаців. Система SHALL не додавати пояснень усередину перекладеного тексту й SHALL окремо повідомляти про суттєву неоднозначність або невідповідність мови вводу.

#### Scenario: Ambiguous source
- **WHEN** без додаткового контексту можливі різні суттєві прочитання
- **THEN** результат супроводжується окремим застереженням або варіантами без вигаданого контексту

### Requirement: Explicit contextual boundaries
Перекладач SHALL використовувати лише текст власного редактора й явно наданий користувачем контекст. Отриманий результат SHALL не надсилатися на повторний переклад без нової дії користувача.

#### Scenario: Selected fragment with context
- **WHEN** користувач перекладає виділення всередині свого тексту
- **THEN** сусідній текст допомагає тлумаченню, але основний результат містить тільки переклад виділення
