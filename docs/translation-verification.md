# Translation implementation evidence

Task 7.3: `npm run test:translation` перевірив усі 12 напрямків `uk/de/en/vi` у 24 forward / reverse cases з різними native roles. REST acceptance використовує stored preferences snapshot; unsupported cross-language direction відхиляється до dispatch. Selection output не містить unselected prefix / suffix; explicit context bounded. Кожна translation має один result, один provider attempt, і профіль не змінюється. Використано локальні PostgreSQL / Redis та deterministic provider double.

Default synthetic policy тепер `double-policy-v5`, prompt `language-v5`. V1–V4 підтримуються без зміни їхньої prompt behavior. V5 успадковує correction / recommendation rules і додає communicative fidelity для translation: intent, facts, numeric digit groups, negation, terminology, degree of commitment, paragraph boundaries і protected literals. Explanation / preamble не включаються у translated text; `ambiguous-input` / `language-mismatch` передаються окремими warnings. Selection context допомагає тлумаченню, але не включається у result. No back-translation або додаткове завдання.

V5 structural validator відхиляє змінені digit groups, відсутні protected terms, неправильну result language та зміну кількості paragraphs. Це консервативні checks, не доказ semantic fidelity; автоматично довести правильність змісту вони не можуть. Mock request tests перевіряють prompt, style / level та explicit context без paid calls. [Synthetic regression](evaluations/double-regression.json) залишається `realModelEvaluation: false`; real model і human review gates task 11.1 не виконані.

Task 7.4: editor direction є session state і не мутує preferences або input. Swap дає нову revision, скасовує старий request та робить попередній результат stale; late response ігнорується. Translator має лише input / primary result, readonly output і одну copy action. Native rendering / edit review / explanation UI належать correction mode. Direction та warnings мають локалізовані labels. Unit tests перевіряють forward / reverse commands і відсутність hidden native operation на web / panel.

Chrome 154.0.8037.57: shared web / panel browser checks і axe пройшли; translator показує окремі ambiguity / language-mismatch warnings і disabled copy для stale result. Native panel + web E2E перевірив reverse selection translation, exact unchanged input, native clipboard write, одну translation operation / attempt та direction swap. Backend defaults `uk/de` залишаються незмінними.
